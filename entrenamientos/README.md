# Biblioteca de entrenamientos DCC

Esta carpeta contiene la nueva biblioteca propia de ejercicios de la app.

## Objetivo

Sustituir progresivamente la biblioteca externa por una selección limpia de ejercicios habituales de gimnasio, con nombres claros en español y una estética visual propia.

## Criterios

- Ejercicios conocidos y fáciles de identificar.
- Prioridad a máquinas, poleas, barras, mancuernas y peso corporal básico.
- Sin variantes exóticas ni nombres innecesariamente técnicos.
- Un identificador estable por ejercicio para enlazar después sus ilustraciones.
- Clasificación por grupo muscular, equipamiento y patrón de movimiento.

## Archivos

- `ejercicios-base.json`: catálogo principal de ejercicios aprobados.
- `ilustraciones/`: aquí se incorporarán después las ilustraciones definitivas de cada ejercicio.

Por ahora esta carpeta no está conectada al flujo actual de la app. Se crea de forma aislada para poder revisar primero el catálogo y las ilustraciones sin afectar a producción.
