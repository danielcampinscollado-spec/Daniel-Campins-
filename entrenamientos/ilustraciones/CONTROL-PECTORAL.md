# CONTROL MAESTRO — PECTORAL

Fuente canónica temporal: `entrenamientos/pectoral-definitivo.json`
Objetivo: 24/24 ilustraciones individuales validadas antes de integrarlas definitivamente en la biblioteca principal de la app.

## Regla operativa
1. Un ejercicio APROBADO no se vuelve a generar salvo petición expresa.
2. Solo se genera un ID PENDIENTE de la lista definitiva de 24.
3. Una imagen debe representar exactamente el ejercicio, equipo, ángulo y trayectoria del ID.
4. Una salida con otro ejercicio, collage, tríptico o postura incorrecta se descarta y no cambia el estado.
5. Los ejercicios de máquina usarán preferentemente arquitectura tipo Hammer Strength cuando corresponda.
6. Cada ejercicio tendrá un asset individual para la app.
