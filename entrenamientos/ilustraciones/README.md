# Ilustraciones de ejercicios

Aquí irán las ilustraciones definitivas de la biblioteca DCC.

Cada archivo debe usar exactamente el mismo identificador del ejercicio en `../ejercicios-base.json`.

Ejemplo:

- Ejercicio: `press-banca-barra`
- Archivo: `press-banca-barra.webp`

Criterio visual pendiente de definir antes de generar el lote completo. No usar ilustraciones antiguas ni recursos externos en esta carpeta.
